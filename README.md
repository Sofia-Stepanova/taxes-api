# taxes-api

API для подбора оптимальной системы налогообложения на основе ввода доходов и расходов.  
Позволяет пользователю добавлять транзакции (доходы/расходы), отслеживать текущий баланс и получать расчёты/сравнение налоговых систем.

## Возможности

- **Управление финансами**: добавление доходов и расходов, просмотр текущего баланса, полный сброс данных.
- **Расчёт налоговой нагрузки**: расчёт налога для выбранной системы налогообложения.
- **Сравнение систем**: получение сравнительной таблицы по всем доступным налоговым режимам.
- **Swagger UI**: интерактивная документация всех эндпоинтов доступна по адресу `/swagger-ui`.
- **Статический фронтенд**: простой интерфейс для работы с API встроен прямо в приложение (в папке `src/main/resources/static`).

## Стек технологий

- Java 21
- Spring Boot 3.1
- Maven
- Lombok
- SpringDoc OpenAPI (Swagger)
- Docker, Docker Compose

## Быстрый старт

### Вариант 1: Запуск через Docker (рекомендуется)

1. Соберите проект локально (чтобы создать JAR):
   ```bash
   mvn package -DskipTests
   
2. Запустите приложение и фронтенд одной командой:
   docker compose up --build
   
3. Откройте в браузере:
   Фронтенд и API: http://localhost:8080
4. Swagger UI: http://localhost:8080/swagger-ui

 ### Вариант 2: Запуск без Docker
    mvn spring-boot:run

 ## Основные эндпоинты и примеры запросов смотрите в Swagger UI.
